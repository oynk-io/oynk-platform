The provider network is modular: Oynk owns a common request and settlement lifecycle while qualified participants supply market-specific liquidity, banking access, collection, exchange, or payout capability.

## Provider profile

A production profile requires legal/KYB status, beneficial ownership, supported corridors and currencies, Stellar and other asset capability, bank/payment integrations, operating hours, amount limits, liquidity/collateral rules, pricing model, service levels, evidence standards, contacts, and suspension state.

## Assignment

The control plane should filter by eligibility first, then evaluate available capacity, price, completion performance, concentration, and risk. A quote is a time-bounded commitment; provider withdrawal, expiry, partial funding, and reassignment need explicit outcomes.

## Performance and lifecycle

Measure accepted assignments, completion time, evidence quality, exception/dispute rate, quote reliability, reconciliation gaps, and availability. Metrics must use verified outcomes rather than provider self-report alone.

Providers need documented onboarding, test activation, limit increases, suspension, incident response, and orderly exit. Removing one provider must not require redesigning the payment application's interface.
