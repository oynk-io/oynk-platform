# Oynk operations console

The Oynk console provides an operational view of indexed on-chain settlement activity. Its connected surfaces currently focus on BSC and Solana transfers recorded across tracked settlement wallets.

## Overview

The Overview separates estimated reference-paired settlement from gross blockchain movement, inflows, and outflows. It also shows tracked wallets, transaction counts, index timestamps, timeline activity, and recent transactions.

## Transactions

The Transactions workspace supports loaded-record search, chain, asset, direction, and date filters; copyable identifiers; paired-leg context where an authoritative reference exists; and direct explorer verification.

## Product areas under development

Payments, settlements, provider operations, wallet cursor inspection, exceptions, reconciliation, analytics, API keys, webhooks, and organizational settings require additional authenticated APIs. They appear as planned console destinations and do not display fabricated production records.

## Operations and architecture

Synchronization health is visible on connected pages. Administrative synchronization and remediation require operator authorization and are not exposed as public browser actions. See the [technical documentation](https://docs.oynk.io/docs) for indexing, settlement, security, and operational architecture.
