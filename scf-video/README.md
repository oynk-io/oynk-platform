# Oynk SCF pitch video package

## Deliverables

- `oynk-scf-openai-voice.mp4`: submission-ready 1080p cut with OpenAI Cedar narration.
- `oynk-scf-narrated-draft.mp4`: synchronized 1080p draft with a neutral synthetic male English voice.
- `oynk-scf-visual-draft.mp4`: original silent 1080p visual draft.
- `narration.md`: timed human narration script.
- `source/slides.html`: editable HTML source for all video scenes.
- `assets/`: authentic Oynk/Stellar captures and the generated opening image.
- `frames/`: rendered 1920×1080 scenes used to assemble the draft.

## Re-rendering

Open `source/slides.html?slide=1` through `slide=12` at 1920×1080 and capture each scene. Assemble the frames using the durations in `source/concat.txt`. Add the recorded narration in any video editor or with FFmpeg, then normalize the final output to H.264/AAC, 1920×1080.

## Generated-image disclosure

The opening commercial-import scene was generated with OpenAI's built-in image generation tool. It is illustrative and does not depict a named Oynk customer, partner or specific market. Product, documentation and Stellar evidence captures are authentic screenshots.

## Narration disclosure

The narration in `oynk-scf-openai-voice.mp4` is AI-generated using OpenAI's Cedar voice. It is directed toward a warm, measured Nigerian-English cadence; it is not a recording of a human speaker.
